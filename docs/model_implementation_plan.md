# 질환 판별 및 위험도 예측 모델 구현 계획서 (갱신)

본 문서는 국민건강영양조사(KNHANES) 전처리 데이터를 활용하여 당뇨병 및 고혈압의 판별 모델과 위험도 예측 모델을 구현하기 위한 상세 계획을 담고 있습니다. 현재 데이터셋 평가 및 초기 모델 구현이 완료된 상태를 반영하여 업데이트되었습니다.

## 1. 개요 및 현재 상태
전처리가 완료된 `apps/ai/data/processed/knhanes/` 데이터를 활용하여 4가지 모델 목표 중 **분류 모델(판별)** 구현 및 평가를 완료했습니다.
- **[완료] 당뇨병/고혈압 판별 모델**: 5개 알고리즘 및 SMOTE 적용 여부에 따른 성능 비교 완료.
- **[진행 예정] 당뇨병/고혈압 위험도 예측 모델**: 확률 기반 예측 및 SHAP 기여도 분석 통합.

## 2. 데이터 분석 결과 반영 (Phase 1 완료)
- **주요 예측 인자**:
    - **당뇨**: `hba1c`(당화혈색소, 0.59), `fbs`(공복혈당, 0.49)가 결정적 요인임.
    - **고혈압**: `sbp`(수축기 혈압), `age`(연령) 및 당뇨 유병 여부가 주요 상관관계 보임.
- **클래스 불균형**: 당뇨(환자 부족), 고혈압(환자 과다) 특성에 따라 SMOTE 적용이 유효함을 확인.

## 3. 모델링 전략 및 최적 모델 선정 (Phase 2 완료)
성능 비교 보고서(`model_comparison_report.md`)를 바탕으로 다음 모델을 베이스라인으로 확정합니다.

| 대상 질환 | 선정 모델 | 선정 사유 |
| :--- | :--- | :--- |
| **당뇨병** | **Gradient Boosting** 또는 **SMOTE-LightGBM** | AUC 0.95 이상의 높은 변별력 및 균형 잡힌 F1-Score |
| **고혈압** | **SMOTE-Logistic Regression** | 낮은 특이도 문제 해결 (0.41 → 0.79) 및 의료 데이터 해석력 우수 |

## 4. [Phase 3] 위험도 예측 및 SHAP 통합 계획 (Next Step)
위험도 예측은 단순 분류를 넘어 **"왜 이 위험도가 도출되었는가"**를 설명하는 것이 핵심입니다.

### 4.1. 위험도 점수 산출
- **방법**: 모델의 `predict_proba()` 결과를 활용하여 0~100점 사이의 위험도 지수로 변환.
- **보정**: 인구 통계적 특성을 반영하여 확률값을 위험 수준(저위험/중위험/고위험)으로 그룹화.

### 4.2. SHAP (SHapley Additive exPlanations) 분석
- **Global Importance**: 전체 인구에서 각 질환에 영향을 미치는 공통 요인 도출.
- **Local Explanation**: 개별 사용자의 예측 결과에 대해 **피처별 기여도(Positive/Negative)** 산출.
    - 예: "현재 당화혈색소 수치가 위험도를 15% 상승시키는 주요 요인입니다."
- **시각화**: `Summary Plot` 및 `Force Plot`을 활용하여 보고서화.

## 5. [Phase 4] 최종 검증 및 서비스화 계획
1. **최종 모델 튜닝**: Optuna 등을 활용하여 베이스라인 모델의 하이퍼파라미터 최적화.
2. **파이프라인 구축**: 데이터 입력부터 전처리, 예측, SHAP 분석까지의 일괄 프로세스 구현.
3. **API 명세 확정**: 예측 결과와 SHAP 기여도를 함께 반환하는 API 구조 설계.
4. **최종 보고서**: 위험도 예측 성능 및 XAI 분석 결과를 포함한 통합 결과 문서 작성.
